This repository is created for the eyetracking-study conducted in the proceedings of the 2026 course " Acquisition and Analysis of Eye-Tracking Data" at University of Stuttgart.

It is a collaborative space used by all (eyeconic) team-members and contains stimuli, experiment-files, participant data and analytical scrips.
